# FitYar development / توسعه فیت‌یار

Use TypeScript and Expo SDK 58 APIs documented at https://docs.expo.dev/versions/v58.0.0/.
از TypeScript و API مستند Expo SDK 58 استفاده کنید.

Run typecheck, lint and tests before release. Keep generated native folders untracked.
پیش از انتشار بررسی نوع، lint و تست اجرا شود. پوشه‌های native تولیدشده وارد گیت نشوند.

Build Android through the repository workflow. Never commit signing secrets or personal health records.
ساخت اندروید از workflow مخزن انجام شود. اسرار امضا و داده سلامت شخصی هرگز وارد گیت نشوند.

All human-facing GitHub text and commit descriptions must be Persian and English. Use Conventional Commits.
متن انسانی گیت‌هاب و شرح کامیت فارسی و انگلیسی باشد. Conventional Commits الزامی است.
